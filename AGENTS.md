# Repository Instructions

Before making any project change, read [PROJECT_MANUAL.md](./PROJECT_MANUAL.md).

For every edit to code, HTML, CSS, assets, dependencies, commands, or documentation:

1. Inspect direct callers and imports.
2. Preserve public APIs and frozen file contracts unless the user explicitly requests otherwise.
3. Use explicit relative ES module paths with `.js`.
4. Avoid circular imports.
5. Run focused syntax and browser verification.
6. Update [PROJECT_MANUAL.md](./PROJECT_MANUAL.md), including its date and change log, in the same edit.
